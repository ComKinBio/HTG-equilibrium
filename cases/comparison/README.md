# Comparison data

Data plotted next to model results (`[comparison]` in a case file). Each CSV has
a `T_C` column and one column per `phase:species`.

- `yakaboylu2013_fig7_8.csv`: approximate digitization of the *calculated*
  equilibrium curves in Yakaboylu et al. (2013), Figures 7 and 8 (240 bar,
  mol/kg dry manure). They are not experimental data.
- `cellulose_matlab.csv`: results of the former MATLAB model from
  `data/Cellulose.xlsx` (sheets "400 C, 275 bar" and "500 C, 275 bar"),
  converted to mol per mol feed carbon.
